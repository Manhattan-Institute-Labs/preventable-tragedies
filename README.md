# Preventable Tragedies (mockup)

A static four-page mockup of the Preventable Tragedies site, a project of the Manhattan Institute.

- `index.html`: landing page (random case, sign-up)
- `stories.html`: the case index (filters, search)
- `facts.html`: the research explainer (scrollytelling charts)
- `solve.html`: five policy proposals

**To preview:** open `index.html` in a browser, or run `python3 -m http.server 8000` in this folder and visit http://localhost:8000.

All copy, cases, photos and chart values are placeholders.

**Working on it with Claude Code:** open this folder and start a session. `CLAUDE.md` holds the project brief, conventions and backlog. `docs/design-system.md` covers the MI brand rules the design follows.
